# Практична робота №3

## Візуалізація структури за допомогою CSS: базові стилі, box model

### Тема
Візуалізація структури за допомогою CSS: базові стилі, box model

### Формат
Комп'ютерний практикум

### Мета роботи
Застосувати CSS до семантично розміченої HTML-структури з практикуму 2: підключити
зовнішній стиль, опанувати основні типи селекторів, свідомо працювати з блоковою моделлю
(box model) - вміст, padding, border, margin - і виконати базове форматування тексту й кольорів
відповідно до кольорової палітри свого варіанта.

### Варіант завдання
**Варіант 7 — Список бажань (Wishlist)**

- **Назва проєкту:** `wishlist-app`
- **Title сторінки:** «Список бажань»

### Необхідні знання й інструменти

- **Знання:** семантична HTML5-розмітка з практикуму 2 (header, main, section, article, aside, footer);
загальне уявлення про те, що таке CSS-правило (селектор і блок оголошень).
- **Інструменти:** ті самі, що й раніше - редактор коду, Live Server, щонайменше два браузери з
DevTools (вкладка Elements з панеллю Styles і діаграмою box model на вкладці Computed), Git.
Стане в пригоді W3C CSS Validator (jigsaw.w3.org/css-validator) для перевірки коректності
стилів.

### Хід роботи

**Крок 1. Підключення зовнішнього стилю**
Створено файл `css/style.css` та підключено його до HTML-документа за допомогою тегу `<link rel="stylesheet" href="css/style.css">` у секції `<head>`. Усі інлайнові стилі видалено для розділення структури та оформлення.

**Крок 2. Додавання базового reset**
На початку файлу `style.css` додано глобальне правило `box-sizing: border-box` для всіх елементів та псевдоелементів. Для тегу `body` встановлено `margin: 0`, щоб прибрати стандартні відступи браузера.

**Крок 3. Налаштування базової типографіки**
Для `body` задано сімейство шрифтів (`font-family`), базовий розмір шрифту (`font-size` у `rem`) та міжрядковий інтервал (`line-height`). Відповідно до вимог індивідуального варіанта застосовано м'яку теплу палітру: встановлено кремовий колір фону сторінки та темний теплий колір тексту.

**Крок 4. Стилізація header**
Шапку сайту оформлено із застосуванням рожевого акцентного кольору фону та золотистого нижнього бордеру (`border-bottom`). Налаштовано внутрішні відступи (`padding`), розмір і світлий колір для заголовка `h1`. Для посилань навігації (`nav a`) налаштовано відступи (`margin-right`) та ефект зміни кольору на золотистий при наведенні (hover).

**Крок 5. Стилізація main і section**
Для основного контейнера `main` задано максимальну ширину (`max-width: 1000px`) та відцентровано його за допомогою `margin: 0 auto`. Додано внутрішні відступи (`padding`) по краях та зовнішні відступи (`margin-bottom: 50px`) між тематичними секціями (`section`).

**Крок 6. Стилізація карток (article)**
Для елементів списку бажань (`article`) задано параметри згідно з варіантом: `padding: 14px`, `border: 1px solid`, `border-radius: 10px` та тінь (`box-shadow`). Додатково реалізовано CSS-модифікатор стану «куплено» (клас `.bought`), який застосовує зменшену прозорість (`opacity: 0.6`) та перекреслює назву товару (`text-decoration: line-through`).

**Крок 7. Стилізація aside й footer**
Блок підсумкової суми (`aside#total`) візуально виділено іншим фоном і пунктирною рамкою. Для самої суми встановлено збільшений розмір шрифту (`1.8rem`). Підвал сайту (`footer`) оформлено з меншим розміром шрифту, відповідними внутрішніми відступами та приглушеним кольором тексту, додано верхню межу.

**Крок 8. Перевірка box model у DevTools**
За допомогою інструментів розробника (DevTools) на вкладці Computed перевірено діаграму Box Model для карток та інших стилізованих елементів. Переконано, що фактичні значення `padding`, `border` та `margin` відповідають заданим у CSS, а ширина елементів обчислюється коректно.

**Крок 9. Валідація та збереження**
Файл `style.css` перевірено валідатором W3C CSS Validator — помилок синтаксису не виявлено. Зміни збережено та зафіксовано в системі контролю версій Git відповідним комітом з описовим повідомленням.
```
git add .
git commit -m "Практична робота №2: семантична розмітка HTML5"
```

### Опис виконаної роботи

1. Створено та підключено зовнішній файл каскадних таблиць стилів style.css, очищено HTML-документ від залишків інлайнових стилів.
2. Застосовано глобальне скидання стилів (reset): встановлено правило box-sizing: border-box для всіх елементів та прибрано стандартні відступи margin: 0 для body.
3. Налаштовано базову типографіку та застосовано кольорову гаму відповідно до м'якої теплої палітри індивідуального варіанта (кремовий фон сторінки, темний колір тексту).
4. Оформлено header із використанням рожевого акцентного фону, налаштовано типографіку головного заголовка h1 та додано hover-ефекти з відступами для посилань у nav.
5. Контентну частину main обмежено за максимальною шириною (1000px) і відцентровано на екрані, а також налаштовано відступи (margin/padding) для візуального розділення секцій section.
6. Картки бажань (article) вишикувано у сітку та стилізовано за специфікацією варіанта: додано padding 14px, border 1px та border-radius 10px.
7. Реалізовано CSS-модифікатор стану «куплено» (клас .bought), який забезпечує напівпрозорість картки (opacity: 0.6) та перекреслює назву товару.
8. Виділено другорядний вміст aside (підсумкову суму) за допомогою пунктирної рамки та великого шрифту 1.8rem, а footer оформлено приглушеними кольорами та меншим кеглем.
9. Перевірено параметри блокової моделі (box model) у DevTools (вкладка Computed), файл стилів провалідовано на відсутність помилок, а зміни збережено в Git.

### Висновок
У результаті виконання практичної роботи до семантично розміченої HTML-структури було успішно застосовано каскадні таблиці стилів (CSS) шляхом підключення зовнішнього файлу. На практиці опановано роботу з основними типами селекторів для точного звернення до структурних елементів сторінки. Закріплено розуміння та використання параметрів блокової моделі (box model): для різних блоків (карток, секцій, форм) коректно налаштовано габарити вмісту, внутрішні (padding) та зовнішні (margin) відступи, а також рамки (border).
